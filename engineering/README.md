# IaaC Engineering

## Purpose

This directory is the canonical engineering memory of the **IaaC**
project.

It preserves the engineering knowledge required to understand, evolve
and maintain the project independently of individual engineers or
historical conversations.

## About the Project

IaaC is the infrastructure automation project responsible for
provisioning, configuring and governing reproducible infrastructure
environments.

## Engineering Areas

-   Engineering Intent
-   Engineering Program
-   Engineering Decisions
-   Project Memory
-   Project Status
-   Roadmap
-   Engineering Knowledge Base (EKB)
-   Operations

## Engineering Principle

Engineering knowledge is treated as a first-class organizational asset.

Source code, conversations, diagrams and documents are evidence of that
knowledge. The Engineering folder is its canonical representation.

## Relationship with the Portfolio

The Engineering folder follows the corporate engineering standard
established by the SPServicesAPI project. Project-specific content may
differ, but the engineering organization remains consistent across the
portfolio.
