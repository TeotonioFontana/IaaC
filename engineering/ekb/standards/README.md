# Standards

## Purpose

This section records the engineering standards governing the project.

## Current Standards

-   Infrastructure is version-controlled.
-   Automation over manual configuration.
-   Idempotent provisioning.
-   Reusable modules first.
-   Environment reproducibility is mandatory.

## Standard Evolution

Engineering standards evolve through controlled engineering decisions.
Changes should preserve portfolio consistency whenever possible.
