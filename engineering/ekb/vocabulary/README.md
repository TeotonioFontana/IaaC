# Vocabulary

## Purpose

This document defines the project's core engineering vocabulary.

## Core Terms

### Infrastructure as Code

Infrastructure defined in source code.

### Module

Reusable infrastructure component.

### Provisioning

Resource creation process.

### Configuration Drift

Difference from desired state.

### Deployment

Applying infrastructure changes.

### Environment

Target infrastructure context.

## Vocabulary Principles

-   Use consistent terminology.
-   Prefer one canonical term for each concept.
-   Record aliases explicitly when needed.
-   Evolve the vocabulary under engineering governance.
